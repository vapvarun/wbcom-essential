# Wbcom Essential - Core Paths (the 60-70%)

> **What nearly every owner uses, ranked.** QA walks these first, every cycle, as the named role,
> on a clean install. A defect on a core path outranks one on an edge.
>
> Seeded from evidence: what the Reign, BuddyX and BuddyX Pro demos insert, the readme lead, the
> docs reading order and the Basecamp ledger (most cards: carousels, grids, colours in dark mode,
> BuddyPress blocks).
