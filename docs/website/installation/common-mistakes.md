# Common Mistakes

Avoid these mistakes to build pages faster and keep them quick to load.

## Searching Plugins > Add New

**Problem:** You search for Wbcom Essential in the plugin directory and find nothing.

**Fix:**

1. The plugin is not on WordPress.org.
2. Install it from **Reign Settings > Extend**, or download the ZIP from [wbcomdesigns.com](https://wbcomdesigns.com/downloads/wbcom-essential/).
3. Use **Plugins > Add New > Upload Plugin** for the ZIP.

## Looking for Blocks That Need Another Plugin

**Problem:** A BuddyPress, WooCommerce or EDD block shows a notice or stays empty.

**Fix:**

1. Install and activate the plugin the block needs: BuddyPress or BuddyBoss Platform, WooCommerce, or Easy Digital Downloads.
2. Reload the editor.
3. Check that the plugin has content, such as members, groups or products.

## Expecting Widgets Without Elementor

**Problem:** You cannot find the Elementor widgets.

**Fix:** Install and activate Elementor. The widgets appear in the **Wbcom Essential** category of the Elementor panel. Blocks do not need Elementor.

## Using the Wrong Block for the Job

| You want | Use |
|----------|-----|
| A sliding showcase | Members Carousel, Group Carousel, Post Carousel, Product Carousel |
| A static directory | Members Grid, Groups Grid, Product Grid |
| A live news strip | Posts Ticker |

## Too Many Carousel Items

**Problem:** A carousel with dozens of items loads slowly, especially on phones.

**Fix:** Limit each carousel to the items visitors will actually swipe through, around 6 to 12. Use a grid for larger sets.

## Not Previewing on Phones

**Problem:** A layout looks right on desktop but breaks on mobile.

**Fix:**

1. Use the Tablet and Mobile controls in the block sidebar.
2. Preview the page on a real phone before publishing.

See [Responsive Design](../features/responsive-design.md).

## Uploading Oversized Images

**Problem:** Large images slow down Hero Section, Promo Banner and carousel blocks.

**Fix:** Resize images to the width they display at, and compress them before upload. See [Performance](../features/performance.md).

## Mixing Colours Block by Block

**Problem:** Each block uses different colours, so the page looks uneven.

**Fix:** Pick a small palette and reuse it. See [Theme Colors](../features/theme-colors.md) to learn how blocks pick up accent colours.

## Overloading the Homepage

**Problem:** Every block on one page makes it slow and hard to scan.

**Fix:** Show one or two community or store sections on the homepage. Link to full directories on their own pages.
