# Common mistakes and how to fix them (Common mistakes)

**Also called:** plugin not found, block empty, widgets missing, slow carousel, page looks wrong on phone, colours uneven, notice in a block.

## What this does

This page lists the mistakes new sites make most. Each one has a fix, so you build pages faster and keep them quick to load.

## Good to know

### Why can't I find the plugin in Plugins > Add New?

The plugin is not on WordPress.org. Install it from **Reign Settings > Extend**. Or download the ZIP from [wbcomdesigns.com](https://wbcomdesigns.com/downloads/wbcom-essential/) and use **Plugins > Add New > Upload Plugin**.

### Why does a block show a notice or stay empty?

The block needs another plugin. Do this:

1. Install and activate the plugin the block needs: BuddyPress or BuddyBoss Platform, WooCommerce, or Easy Digital Downloads.
2. Reload the editor.
3. Check that the plugin has content, such as members, groups or products.

### Where are the Elementor widgets?

Install and activate Elementor. The widgets appear in the **Wbcom Essential** category of the Elementor panel. Blocks do not need Elementor.

### Which block fits the job?

| You want | Use |
|----------|-----|
| A sliding showcase | Members Carousel, Group Carousel, Post Carousel, Product Carousel |
| A static directory | Members Grid, Groups Grid, Product Grid |
| A live news strip | Posts Ticker |

### Why is my carousel slow?

A carousel with dozens of items loads slowly, especially on phones. Limit each carousel to the items visitors will actually swipe through, around 6 to 12. Use a grid for larger sets.

### Why does my page break on a phone?

A layout can look right on desktop but break on mobile. Do this:

1. Use the Tablet and Mobile controls in the block sidebar.
2. Preview the page on a real phone before publishing.

See [Phone and tablet layouts](../features/responsive-design.md).

### Why are my banners slow to load?

Large images slow down Hero Section, Promo Banner and carousel blocks. Resize images to the width they display at, and compress them before upload. See [Page speed](../features/performance.md).

### Why do my colours look uneven?

When each block uses different colours, the page looks uneven. Pick a small palette and reuse it. See [Match your theme's colours](../features/theme-colors.md) to learn how blocks pick up accent colours.

### Why is my home page slow and busy?

Every block on one page makes it slow and hard to scan. Show one or two community or store sections on the homepage. Link to full directories on their own pages.

## You'll know it worked when

The block shows content, your plugin shows in the admin, and the page loads quickly on a phone.
