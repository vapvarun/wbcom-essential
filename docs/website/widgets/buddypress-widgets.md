# BuddyPress Widgets

The 11 BuddyPress widgets show members, groups, forums and profile information. They appear in the Elementor panel under the **Wbcom Essential** category.

Every widget in this group needs BuddyPress or BuddyBoss Platform. The three group widgets (Group Carousel, Groups Grid, Groups Lists) also need the BuddyPress Groups component. The two forum widgets (Forums, Forums Activity) also need bbPress. A widget whose plugin is missing does not appear in the panel.

## Dashboard Intro

A greeting for the logged-in member with their avatar and a short description.

### Content settings

| Setting | What it does |
|---------|--------------|
| Position | Places the avatar to the left, above or to the right of the text. |
| Alignment | Aligns the text left, centre or right. |
| Greeting & Description | Greeting text. The default is "Welcome". |
| Description | Text after the member name. The default is "to your Member Dashboard". |

### Style settings

| Setting | What it does |
|---------|--------------|
| Avatar | Size, border, padding, radius, shadow and spacing. |
| Content | Greeting and description colours, plus typography for the greeting, name and description. |

## Forums

A list of your bbPress forums. Needs bbPress.

### Content settings

| Setting | What it does |
|---------|--------------|
| Layout | Forums Count, Row Space, Show All Forums Link, Show Avatar, Show Meta Data, Show Meta Replies and Show Last Reply. |
| Content | Heading Text and Forum Link Text. |

### Style settings

| Setting | What it does |
|---------|--------------|
| Box | Border, radius, background, and the All Forums link and its colour. |
| Avatar | Size, border, radius, opacity and spacing. |
| Content | Title typography, title and link colours in Normal and Hover states, content typography, meta data colour and last reply colour. |

## Forums Activity

The current member's recent forum discussions, with a button to see them all. Needs bbPress.

### Content settings

| Setting | What it does |
|---------|--------------|
| Layout | Show Forum Title, Show Meta Data, Show Excerpt, Show Reply Icon, Show Link with its Button Text, and the My Discussions Button with its text. |
| Content | No Forums Paragraph Text and No Forums Button Text, shown when there is nothing to list. |

### Style settings

| Setting | What it does |
|---------|--------------|
| Box | Border, radius, background and padding. |
| Content | Colour, typography and spacing for the forum title, topic title, meta data and excerpt. |
| Button, My Discussions Button | Colours, border and typography in Normal and Hover states, alignment, padding and spacing. |

### Content settings

| Additional Options | Groups to Show, Groups to Scroll, Navigation, Autoplay, Pause on Hover, Pause on Interaction, Autoplay Speed, Infinite Loop, Effect, Animation Speed and Direction. |

## Groups Grid

A grid of BuddyPress groups. Needs the Groups component.

### Content settings

| Setting | What it does |
|---------|--------------|
| Sort | Newest, Most Active, Most Popular, Random or Alphabetical. |
| Total groups | How many groups to show. The default is 12. |

## Header Bar

A header bar with a profile dropdown, search, messages, connections, notifications and a WooCommerce cart. Logged-out visitors see sign-in and sign-up buttons.

### Content settings

| Setting | What it does |
|---------|--------------|
| Content | Show or hide Profile Dropdown, Menu, Separator, Search, Messages, Connections, Notifications and Cart. |
| Icons | Choose the icon for Search, Messages, Connections, Notifications, Cart, Dark Mode and Toggle Sidebar. |

### Style settings

| Setting | What it does |
|---------|--------------|
| Header Bar Layout | Alignment, spacing, separator width and colour, and the counter badge colour and shadow. |
| Icons | Size, shadow, and colours for all icons or for each icon. |
| Profile Dropdown | Display name typography and colours, avatar size and border, and the dropdown typography, background and menu item colours. |
| Logged Out | Typography and colours for the sign-in and sign-up buttons. |

### Tips

- Messages, Connections and Notifications show only when the matching BuddyPress component is active.
- The cart shows only when WooCommerce is active.
- On the Reign, BuddyX and BuddyX Pro themes, the logged-out buttons use the theme's own header parts. On other themes they link to the standard WordPress login and registration pages.

## Profile Completion

Shows how much of the member's profile is complete, with a button to finish or edit it.

### Content settings

| Setting | What it does |
|---------|--------------|
| Layout | Skin (Circle or Linear), Alignment and Hide Widget. |
| Profile Complete Button | Heading Text, Completion Text, Complete Profile Button Text and Edit Profile Button Text. |

### Style settings

| Setting | What it does |
|---------|--------------|
| Box | Width, background, border and radius. |
| Progress Graph | Spacing, border width and typography for the heading, value, info and data. |
| Colors | Heading, completion, incomplete, border, number and text colours. |
| Details Dropdown | Show Header, Show Completion Icon, Show Completion Status, shadow and typography. |
| Button | Colours, border and typography in Normal and Hover states, padding, border and spacing. |
