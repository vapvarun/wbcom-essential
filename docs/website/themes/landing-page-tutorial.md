# Landing Page Tutorial

Build a product or service landing page with Wbcom Essential blocks. No other plugin is needed.

## Step 1: Create the Page

1. Go to **Pages > Add New**.
2. Name the page and open the block inserter with **+**.

## Step 2: Hero Section

1. Insert **Hero Section** from **Essential - Marketing**.
2. Set the heading and subheading.
3. Set the two buttons, for example "Get Started" and "Learn More".
4. Choose a gradient or image background.

## Step 3: Rotating Tagline (Optional)

1. Insert **Text Rotator** from **Essential - Design**.
2. Add the phrases to rotate and choose fade, slide or typewriter.

## Step 4: Features

1. Insert **Feature Grid** from **Essential - Marketing**.
2. Add a card for each feature with an icon or emoji, a title and a description.
3. Pick the elevated, bordered or flat card style.

## Step 5: Numbers

1. Insert **Stats Counter** from **Essential - Design**.
2. Add up to 6 stats, such as customers, countries or years in business.

## Step 6: Social Proof

1. Insert **Testimonial Carousel** from **Essential - Marketing**.
2. Add the quotes and choose dots, arrows or autoplay.

## Step 7: Pricing

1. Insert **Pricing Table** from **Essential - Marketing**.
2. Set 1 to 4 plans, mark one as featured, and add a button to each plan.

## Step 8: Questions

1. Insert **FAQ Accordion** from **Essential - Content**.
2. Add your questions and answers. The block outputs FAQ schema for search engines.

## Step 9: Limited-Time Offer (Optional)

1. Insert **Countdown Timer** from **Essential - Marketing**.
2. Set the target date and time and an expiry message.

## Step 10: Final Call to Action

1. Insert **CTA Section** from **Essential - Marketing**.
2. Add a heading, description and one button.

## Step 11: Publish and Test

1. Click **Publish**.
2. Check the page at desktop, tablet and phone sizes.

## Using Elementor

Use the **Slider**, **Flip Box**, **Pricing Table**, **Testimonial Carousel**, **Countdown** and **Accordion** widgets from the **Wbcom Essential** category.
