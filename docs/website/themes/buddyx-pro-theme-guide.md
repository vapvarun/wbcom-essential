# BuddyX Pro Theme Guide

Wbcom Essential is part of BuddyX Pro. This page shows which blocks and widgets suit common BuddyX Pro sites.

## Install Wbcom Essential

1. Download the plugin from [wbcomdesigns.com](https://wbcomdesigns.com/downloads/wbcom-essential/).
2. Go to **Plugins > Add New > Upload Plugin**.
3. Upload the ZIP, install it and click **Activate Plugin**.

Wbcom Essential is not on WordPress.org, so do not search for it in **Plugins > Add New**.

## Blocks and Widgets by Site Type

### Community

| Goal | Block | Elementor widget |
|------|-------|------------------|
| Member directory preview | Members Grid, Members Carousel | Members Grid, Members Lists |
| Group directory preview | Groups Grid, Group Carousel | Groups Grid, Groups Lists |
| Recent updates | Activity Feed | - |

### Store

| Goal | Block | Elementor widget |
|------|-------|------------------|
| Products | Product Grid, Product Carousel | Universal Product |
| Reviews | Customer Reviews | Customer Review |
| Sale banner | Promo Banner, Countdown Timer | Add Banner, Countdown |

### Digital Downloads

If you sell with Easy Digital Downloads, use the EDD blocks: Product Catalog, Account Dashboard, Order Success and the checkout section blocks. See [EDD Blocks](../blocks/edd-blocks.md).

### Business

Use Hero Section, Feature Grid, Pricing Table, FAQ Accordion and CTA Section. See [Marketing Blocks](../blocks/marketing-blocks.md) and [Content Blocks](../blocks/content-blocks.md).

## Colours in Blocks

Blocks take their accent colour from the `--wbcom-link-color` CSS variable and fall back to a default blue. See [Theme Colors](../features/theme-colors.md).
