# Online Store Tutorial

Build a store homepage with Wbcom Essential blocks. You need WooCommerce with some products.

## Before You Start

1. Activate WooCommerce.
2. Add products with images and prices.
3. If you want the reviews block to show content, collect a few product reviews.

## Step 1: Create the Page

1. Go to **Pages > Add New**.
2. Name it "Home" or "Shop Home".

## Step 2: Hero Section

1. Insert **Hero Section** from **Essential - Marketing**.
2. Add a heading, subheading and a button that links to your shop page.

## Step 3: Featured Products

1. Insert **Product Carousel** from **Essential - WooCommerce**.
2. Set autoplay, arrows, dots and slides per view for each screen size.

## Step 4: Promotion

1. Insert **Promo Banner** from **Essential - Marketing**.
2. Add an image, overlay text and a button.
3. For a time-limited sale, add **Countdown Timer** below it.

## Step 5: Product Grid

1. Insert **Product Grid** from **Essential - WooCommerce**.
2. Choose a category filter and the number of columns.

## Step 6: Customer Reviews

1. Insert **Customer Reviews** from **Essential - WooCommerce**.
2. The block shows reviews with avatar, star rating, reviewer name and product link.

## Step 7: Final Call to Action

1. Insert **CTA Section** from **Essential - Marketing**.
2. Link the button to your shop or newsletter page.

## Step 8: Publish and Test

1. Click **Publish**.
2. View the page as a visitor and add a product to the cart.
3. Check it on a phone.

## Using Elementor

Use the **Universal Product**, **Product Tab**, **Add Banner**, **Customer Review** and **WooCommerce Testimonial** widgets from the **Wbcom Essential** category.
