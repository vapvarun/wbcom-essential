# BuddyX Theme Guide

Wbcom Essential is part of BuddyX. This page shows which blocks and widgets suit common BuddyX sites.

## Install Wbcom Essential

1. Download the plugin from [wbcomdesigns.com](https://wbcomdesigns.com/downloads/wbcom-essential/).
2. Go to **Plugins > Add New > Upload Plugin**.
3. Upload the ZIP, install it and click **Activate Plugin**.

Wbcom Essential is not on WordPress.org, so do not search for it in **Plugins > Add New**.

## Blocks and Widgets by Page

### Community Homepage

| Section | Block | Elementor widget |
|---------|-------|------------------|
| Intro | Hero Section | Heading, Slider |
| New members | Members Carousel | Members Carousel |
| Active groups | Groups Grid | Groups Grid |
| Latest updates | Activity Feed | - |
| Join prompt | CTA Section | - |

### Blog or Magazine Page

| Section | Block | Elementor widget |
|---------|-------|------------------|
| News strip | Posts Ticker | Posts Ticker |
| Featured posts | Post Carousel | Post Slider, Posts Carousel |
| Browse topics | Category Grid | - |
| History | Timeline | Post Timeline, Timeline |

### Landing Page

Use Hero Section, Feature Grid, Pricing Table, Testimonial Carousel and CTA Section. See [Landing Page Tutorial](landing-page-tutorial.md).

## Colours in Blocks

Blocks take their accent colour from the `--wbcom-link-color` CSS variable and fall back to a default blue. See [Theme Colors](../features/theme-colors.md).
