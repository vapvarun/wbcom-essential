# WooCommerce Integration

Wbcom Essential includes 3 WooCommerce blocks and 5 WooCommerce Elementor widgets. They work with WooCommerce 7.0 or later.

## What You Need

1. Install and activate WooCommerce.
2. Add products and, for reviews, collect some product reviews.

If WooCommerce is inactive, a WooCommerce block shows "WooCommerce plugin is required for this block."

## Blocks

| Block | Shows |
|-------|-------|
| Product Grid | Products in a responsive grid with category filter, sale badge, star rating and add-to-cart button |
| Product Carousel | Products in a carousel with autoplay, arrows and dots |
| Customer Reviews | Product reviews in a carousel with avatar, star rating, reviewer name and product link |

Details: [WooCommerce Blocks](../blocks/woocommerce-blocks.md).

## Elementor Widgets

All widgets are in the **Wbcom Essential** category and appear only when WooCommerce is active.

| Widget | Purpose |
|--------|---------|
| Universal Product | Product display |
| Product Tab | Products in tabs |
| Add Banner | Promotional banner |
| Customer Review | Product reviews |
| WooCommerce Testimonial | Testimonials from WooCommerce |

Details: [WooCommerce Widgets](../widgets/woocommerce-widgets.md).

## Page Ideas

- **Shop homepage:** Hero Section, Product Carousel, Promo Banner, Product Grid, Customer Reviews, CTA Section.
- **Sale page:** Countdown Timer above a Product Grid filtered to a sale category.
