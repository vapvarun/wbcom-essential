# Community Site Tutorial

Build a community homepage with Wbcom Essential blocks. You need BuddyPress or BuddyBoss Platform, with some members and groups.

## Before You Start

1. Activate BuddyPress or BuddyBoss Platform.
2. Go to **Settings > BuddyPress > Components** and enable Members, Activity and User Groups.
3. Create a few test members and groups so the blocks have content.

## Step 1: Create the Page

1. Go to **Pages > Add New**.
2. Name it "Home" or "Community".

## Step 2: Add a Hero Section

1. Click **+** and open **Essential - Marketing**.
2. Insert **Hero Section**.
3. Set the heading, subheading and the two buttons, for example "Join the Community" and "Browse Groups".

## Step 3: Show Your Members

1. Insert **Members Carousel** from **Essential - BuddyPress**.
2. Set how many members to show and the carousel options in the sidebar.

## Step 4: Show Your Groups

1. Insert **Groups Grid** from **Essential - BuddyPress**.
2. Choose how groups are sorted and how many columns to show for each screen size.

## Step 5: Show Recent Activity

1. Insert **Activity Feed** from **Essential - BuddyPress**.
2. Adjust the number of items and what each card shows.

## Step 6: Add a Join Prompt

1. Insert **CTA Section** from **Essential - Marketing**.
2. Add a heading such as "Ready to join?" and set the button link to your registration page.

## Step 7: Add a Login Form (Optional)

1. Insert **Login Form** from **Essential - Content**.
2. Set the redirect URL and turn on the register and lost-password links.

## Step 8: Publish and Test

1. Click **Publish**.
2. View the page logged out and logged in.
3. Check it on a phone.

## Using Elementor

Use the **Members Carousel**, **Groups Grid**, **Dashboard Intro** and **Login Form** widgets from the **Wbcom Essential** category.
