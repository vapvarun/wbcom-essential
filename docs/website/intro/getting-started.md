# Getting Started

This guide builds a simple landing page with Wbcom Essential blocks. It takes about 10 minutes. Install and activate the plugin first: see the [Installation Guide](../installation/installation-guide.md).

## Add Your First Block

1. Go to **Pages > Add New**.
2. Click the **+** button to open the block inserter.
3. Scroll to the **Essential - Marketing** category, or search for "Hero".
4. Click **Hero Section** to insert it.
5. Select the block and use the right sidebar to change the heading, subheading, buttons and background.

## Build a Simple Landing Page

Add these blocks in order.

| Order | Block | Inserter category | Purpose |
|-------|-------|-------------------|---------|
| 1 | Hero Section | Essential - Marketing | Headline and two buttons |
| 2 | Feature Grid | Essential - Marketing | Feature cards |
| 3 | Stats Counter | Essential - Design | Animated numbers |
| 4 | Testimonial Carousel | Essential - Marketing | Customer quotes |
| 5 | CTA Section | Essential - Marketing | Final call to action |

1. Insert each block from the table above.
2. Edit the text in the editor or in the block sidebar.
3. Click **Publish**.
4. Open the page and check it on your phone.

Every block has Desktop, Tablet and Mobile controls, so you can adjust layout per screen size. See [Responsive Design](../features/responsive-design.md).

## Using Elementor Instead

1. Install and activate Elementor.
2. Edit a page with Elementor.
3. Find the **Wbcom Essential** category in the widget panel.
4. Drag a widget, such as **Slider**, **Pricing Table** or **Testimonial Carousel**, onto the page.

## Add Community or Store Content

- BuddyPress site: add **Members Grid** or **Activity Feed**. See [BuddyPress Blocks](../blocks/buddypress-blocks.md).
- WooCommerce store: add **Product Grid**. See [WooCommerce Blocks](../blocks/woocommerce-blocks.md).
