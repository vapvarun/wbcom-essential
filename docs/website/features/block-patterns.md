# Block Patterns

Block patterns are ready-made layouts you insert in one click and then edit. Wbcom Essential adds 12 of them, built from its own blocks. You do not need to configure anything.

## Insert a pattern

1. Edit a page or post in the block editor.
2. Click the **+** button and open the **Patterns** tab.
3. Choose the category **WBcom Essential - Magazine** or **WBcom Essential - Single Post**.
4. Click a pattern to insert it, then edit the blocks as usual.

## Magazine patterns

| Pattern | What it is |
|---------|------------|
| Blog Editorial | An editorial-style blog layout with a hero slider and a magazine grid. |
| Blog Featured List | A featured hero post with a sidebar grid, followed by a side-by-side post list. |
| Blog Listing | A clean blog listing with side-by-side post cards and pagination. |
| Blog Masonry | A masonry-style 3-column blog grid with category navigation. |
| Blog Timeline | A chronological two-column timeline layout for blog posts. |
| Category Archive | A category archive page with a post grid and a sidebar of the latest posts. |
| Magazine Homepage | A full news site homepage with a breaking news ticker, hero post slider, featured posts grid and category grid. |
| News Dashboard | A multi-section news dashboard with a hero, category spotlight columns and more stories. |

## Single post patterns

| Pattern | What it is |
|---------|------------|
| Author Bio Section | An author bio section with a divider and a testimonial-style layout. |
| Newsletter CTA | A centered newsletter sign-up call to action. |
| Related Posts Carousel | A related posts carousel with a divider and heading. |
| Share Section | A share section with text and social media icons. |

Insert single post patterns at the end of a post, or wherever the section belongs.

## Tips

- A pattern is a starting point. Each block inside it has its own settings, described in [Blog Blocks](../blocks/blog-blocks.md), [Marketing Blocks](../blocks/marketing-blocks.md) and [Content Blocks](../blocks/content-blocks.md).
- Post Carousel inside the magazine patterns reads your latest posts. Choose categories in the block settings to narrow them.
- If a pattern does not appear, check that Wbcom Essential is active and your WordPress version is 6.0 or later.
